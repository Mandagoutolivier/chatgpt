# Sources historiques exclues des constructions

Les trois modules dans `Vba/` étaient déjà absents du manifeste actif U0/U1. Ils sont déplacés ici sans modification de leurs octets. Les suppressions autorisées de leurs anciens composants restent dans le manifeste de construction.

Leurs remplaçants actifs sont `modApiConfiguration`, `modDemandesAnnexes` et `modDestinations`. L'historique Git conserve les anciens chemins. Aucun fichier de ce dossier ne doit être importé dans les modèles de production ou de recette.

Les signatures publiques historiques conservées ailleurs sont des adaptateurs vers le parcours unifié ou des refus explicites ; elles ne réactivent pas un ancien moteur de correction ou d'annexes.
